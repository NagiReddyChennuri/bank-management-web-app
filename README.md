# 🏦 Apex Bank Management System (Full-Stack)

A modern, responsive, and beginner-friendly full-stack Bank Management Web Application built with **Node.js**, **Express.js**, **SQLite**, and **Vanilla HTML5/CSS3/JavaScript**.

---

## 🚀 Key Features

- **Account Lifecycle Management**: Open new accounts with auto-generated account numbers, live directory search, multi-criteria sorting, and customer details editing.
- **PIN Security & Verification**: Strict 4-digit Security PIN authorization required for all financial operations. Mandatory Current PIN verification to modify account credentials.
- **Deposit & Withdrawal Engine**: Process deposits and withdrawals with real-time balance calculations and **overdraft prevention**.
- **Transaction Statement Logs**: Comprehensive audit trail of all transactions with timestamps, descriptions, and color-coded transaction badges.
- **Real-Time Financial Analytics**: Live KPI cards tracking **Total Bank Liquidity**, **Active Accounts Count**, **Total Deposits**, and **Total Withdrawals**.
- **Localized Currency**: Standard **Indian Rupee (INR / ₹)** formatting with Indian numbering representation (`₹1,50,000.00`).
- **Zero Heavy Frameworks**: Pure vanilla frontend ensuring ultra-fast load times and lightweight execution.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom Responsive Financial Theme), Vanilla JavaScript (Async/Await `fetch` API)
- **Backend**: Node.js, Express.js (RESTful API architecture)
- **Database**: SQLite3 (`sqlite3` driver with parameterized SQL queries preventing SQL injection)
- **Deployment**: Render / Railway / Node.js hosting
